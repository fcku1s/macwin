💻 Windows / Mac 客户端配置教程

Clash Verge · 从下载安装到节点使用的完整教程

📦 第一步：下载 Clash Verge

🪟 下载 Windows 版 🍎 下载 macOS（M 芯片） 🍎 下载 macOS（Intel 芯片）
💡 Mac 用户请根据电脑芯片选择版本：
M1 / M2 / M3 / M4 等 Apple 芯片 → 选择 aarch64
Intel 芯片 → 选择 x64

2 选择安装语言

  1. 打开 Clash Verge 安装程序。
  2. 出现语言选择窗口后，默认选择「中文（简体）」即可。
  3. 点击「OK」。

3 开始安装

  1. 进入安装程序欢迎界面。
  2. 点击「下一步(N)」。

4 选择安装位置

  1. 保持默认安装目录即可。
  2. 点击「下一步(N)」。
  3. 等待软件安装完成。

5 打开软件并进入订阅

  1. 安装完成后打开 Clash Verge。
  2. 进入首页。
  3. 找到「订阅」区域。
  4. 点击「导入订阅」。

6 打开官网仪表盘

  1. 打开会员中心：dankewed.com
  2. 登录你的账户。
  3. 点击顶部「仪表盘」。
  4. 找到你的套餐信息。
  5. 点击橙色的「导入订阅」按钮。

7 复制订阅地址

  1. 在弹出的「导入订阅」窗口中找到对应分类。
  2. Windows 用户选择 Windows。
  3. Mac 用户选择 MacOS。
  4. 点击「复制订阅地址」。
💡 点击复制后，订阅地址会自动保存到剪贴板。

8 粘贴订阅地址

  1. 回到 Clash Verge。
  2. 进入「订阅」页面。
  3. 在顶部输入框粘贴刚才复制的订阅地址。
  4. 点击「导入」。

9 打开代理节点列表

  1. 点击左侧「代理」。
  2. 找到当前代理组。
  3. 点击右上角数字或箭头图标。
  4. 展开完整节点列表。

10 测速并选择节点

  1. 点击右上角闪电 ⚡ 图标。
  2. 等待所有节点完成测速。
  3. 查看节点延迟。
  4. 通常延迟数值越低，连接响应越快。
  5. 选择一个适合自己的地区节点。

11 开启系统代理

  1. 回到左侧「首页」。
  2. 找到「网络设置」。
  3. 找到「系统代理」。
  4. 点击右侧开关。
  5. 开关变成绿色后，即表示已经开启。
💡 推荐普通用户优先使用「系统代理」。 浏览器以及支持系统代理的软件通常会自动使用代理连接。

12 无法代理时开启虚拟网卡模式

  1. 如果部分软件无法正常联网，可以尝试开启虚拟网卡模式。
  2. 进入 Clash Verge「网络设置」。
  3. 找到「虚拟网卡模式」。
  4. 点击右侧开关。
  5. 首次开启可能会要求管理员权限，请根据系统提示操作。
⚠️ 虚拟网卡模式（TUN）会接管更多系统网络流量。 如果只是浏览网页，通常优先使用「系统代理」即可。

🎉 配置完成

现在 Clash Verge 已经完成基本配置。

选择需要使用的节点后， 开启「系统代理」即可开始使用。

如果某个节点速度较慢，可以重新测速并更换其他节点。
